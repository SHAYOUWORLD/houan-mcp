# ADR 0005 — 衆議院議案一覧の URL・表解析と検索失敗の通知

- Status: Accepted
- Date: 2026-10-28
- Related: ADR 0002

## 確認した問題

公式の第221・222回一覧は `kaiji{session}.htm` にあり、従来の `{session}/{session}gian.htm` はいずれも HTTP 400。新しい一覧は「提出回次・番号・議案件名・審議状況・経過情報・本文情報」の構成で、件名はリンクではない。旧実装は回次を議案番号に、リンクの「経過」を件名にする。経過・本文の相対リンクも、回次のサブディレクトリを挟まず解決する必要がある。

第222回一覧には第221回提出の継続案件がある。条約表にはヘッダーを囲む `<tr>` がなく、承諾・決算等には番号列がない。本文未掲載の案件もある。審議経過ページは「項目・内容」の表で、ラベル内に span が入るため、従来のラベル直後を読む正規表現では提出者・付託・結果を取得できない。

## 決定

- 一覧 URL を `kaiji{session}.htm` にし、リンクをその URL に対して解決する。
- 列名で表を解析する。表の列数・必須項目・番号を検証し、想定外の HTML を正常な0件と扱わない。本文・経過情報の未登録は null。
- `session` は検索回次として維持し、提出回次を `submittedSession`、種類を `billType` に追加。番号のない案件の `billNumber` は null。
- 既定回次とツールスキーマ・README の説明を222に揃える。自動で最新回次を調べる通信は追加しない。（ADR 0006 で変更：回次未指定時は衆議院の回次一覧から最新を読み、222は読めないときの代替値とする）
- 衆議院の `get_bill` は項目・内容の行を解析し、件名、番号、提出者、委員会、審議結果と経過を返す。公式に値がない項目は null と警告を返し、受理日を提出日として代用しない。
- 検索時の取得・解析失敗は `isError: true` の MCP ツール結果とし、`sourceErrors` に院・URL・原因を含める。両院検索でも一方の失敗時は全体を失敗とし、不完全な件数を正常な結果として返さない。
- 参議院の URL・正常時の解析結果、NDL ツールの挙動は維持する。参議院の通信失敗も同じエラー経路に乗せる。
- 公式 HTML の抜粋を保存し、実サーバープロセスに対するオフライン回帰テストを追加する。依存パッケージは追加しない。

## 範囲・制約

HTML の構造がさらに変われば追加対応が必要。ヘッダーだけの認識可能な空の表は有効な0件として扱う。実行時の既定回次は定数なので、次回国会時は更新または呼び出し側で回次指定が必要（ADR 0006 で解消）。

NDL の送信直列化・間隔制御（PR #6）、Node.js の対応バージョン、公開バージョン、タグ、npm / MCP Registry のリリースは変更しない。
